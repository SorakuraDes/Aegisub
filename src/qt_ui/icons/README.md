# Material Symbols Outlined

These SVGs are the unmodified 24 px Material Symbols Outlined from
[Google's Material Design Icons repository](https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web).
The upstream path for `<name>.svg` is
`symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg` at commit
`10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`.

Licensed under the [Apache License, Version 2.0](LICENSE). The resource bundle
includes this notice and the upstream license alongside the icons. QML controls
apply their theme colors at runtime rather than modifying the source artwork.

`follow_playhead.svg` and the four `format_*.svg` files are local artwork
created for the Qt frontend, not imported Material Symbols.
